Mission 1 · Search and guided evacuation

Post-earthquake building, interior unknown. All drones start at the launch pad. No leader, and no planned way in or out. Each drone keeps its own copy of a binary Merkle task tree, built only from what its neighbours send. It claims one leaf and releases it only when the leaf's success criteria hold. The flying swarm never splits its radio network.

Get every person in the building to the designated safe area.

Arrows between drones are directed links, one per direction. An orange link is critical: it is a drone's only way into the rest of the network, so the drone will not fly out of range of it. The dashed ring around a drone is its position uncertainty σ. It shrinks when neighbours range the drone (dashed purple lines). Root hash of each drone's tree same colour = same tree

The Merkle hash of a node covers its children, so two drones with the same root hash hold the same tree. Neighbours compare root hashes first and send tree updates only when they differ. Then only the branches with different hashes are sent.

Row = a drone's own copy of the tree; column = a leaf. A red column header means two drones currently claim the same leaf. Because the swarm is decentralized this can happen, and it resolves when their trees meet: the better-suited drone keeps the leaf (lower ID on a tie). ✓ = done, · = open, blank = not in that drone's tree yet.

Success metrics families from the mission brief · measured against ground truth

Leaf scores computed by D0 –

Score = priority × capability fit × battery factor − distance cost. A free drone runs a greedy assignment over the open leaves and the free teammates it has heard from recently, and claims its own pick if the score is at or above the threshold. A drone with a leaf keeps it until the leaf is done, unless a teammate in radio range offers a swap that helps both.
